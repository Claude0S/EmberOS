## Скачать

Готовый ISO лежит на странице **[Releases](../../releases/latest)**: файл `emberos-….iso`, около 1,8 ГБ.

Каждая сборка автоматически проверяется перед публикацией:
- живая система загружается до рабочего стола в виртуальной машине;
- настройки установщика проверяются по официальным схемам Calamares;
- Ember OS устанавливается на виртуальный диск, перезагружается и должна дойти до рабочего стола.

Скриншоты этих проверок прикреплены к каждому релизу.

## Что внутри

- **Рабочий стол** Hyprland: полупрозрачные окна, плавные анимации, панель, док, обои с озером на закате
- **Виджеты**: музыка (Spotify, YouTube в Firefox, любой плеер), часы, погода, процессор / память / батарея. Перетаскиваются мышкой
- **Win + Enter** открывает командную строку Ember на весь экран, `/desktop` возвращает назад
- **Программы**: Firefox, Claude в отдельном окне, Steam, Hydra Launcher, файлы `.exe` открываются двойным кликом
- **Драйверы** ставятся автоматически под любое железо (Intel, AMD, NVIDIA, Wi-Fi, звук, ноутбуки)
- **Установщик** с подключением Wi-Fi: стереть диск / рядом с Windows / заменить раздел / вручную
- **Красивая загрузка**: меню загрузки, заставка с лисёнком, экран входа и блокировки
- **Языки**: українська, English, русский

## Команды (Win + Enter)

| Команда | Что делает |
|---|---|
| `/search котики` | открыть Firefox с поиском |
| `/desktop` | вернуться на рабочий стол |
| `/download steam` | установить программу (`/apps` — список) |
| `/little` · `/full` | лёгкий режим для старых компьютеров · полный режим |
| `/widgets` | виджеты: `on` / `off` / `opacity` / `scale` / `reset` |
| `/theme night` | тема: `ember`, `night`, `ocean`, `forest`, `sakura`, `mono` (цвета, лисёнок и обои вместе) |
| `/mascot ember` | лисёнок от другой темы (`auto` — как у темы) |
| `/wallpaper ocean` | обои от другой темы или свой файл: `/wallpaper ~/Pictures/фото.jpg` (`auto` — как у темы) |
| `/status` | процессор, память, диск, батарея |
| `/drivers` | проверить и установить драйверы |
| `/wifi` · `/update` · `/files` | Wi-Fi · обновление системы · проводник |
| `/lang uk` · `/lang en` · `/lang ru` | язык интерфейса |

Всё, что написано без `/` в начале, выполняется как обычная команда терминала.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Win + Enter` | командная строка Ember (показать / скрыть) |
| `Win + D` | меню программ |
| `Win + T` · `Win + E` · `Win + B` | терминал · файлы · браузер |
| `Win + Q` | закрыть окно |
| `Win + F` | на весь экран и обратно |
| `Win + V` | сделать окно свободным (двигать и менять размер, как в Windows) |
| `Win` + перетаскивание левой кнопкой | переместить окно |
| `Win` + перетаскивание правой кнопкой | изменить размер окна |
| `Win + 1…9` | перейти на рабочий стол 1…9 |
| `Win + Shift + 1…9` | отправить окно на рабочий стол 1…9 («спрятать», не закрывая) |
| `Win + L` | заблокировать экран |
| `Print` · `Shift + Print` | скриншот области (копируется) · скриншот всего экрана (в Pictures) |
| `Alt + Shift` | раскладка EN → UA → RU |

## Как попробовать

**VirtualBox:** создай новую ВМ с типом *Linux / Arch Linux (64-bit)*, 4 ГБ памяти, 2+ ядра и диском 30 ГБ.
В разделе Display выбери Graphics Controller **VMSVGA**, включи **3D Acceleration** и поставь Video Memory 128 МБ. Подключи ISO и запусти.

**Флешка:** запиши ISO через [Ventoy](https://www.ventoy.net), balenaEtcher или Rufus. В Rufus на вопрос о режиме выбирай **DD-образ**.
Перед этим выключи **Secure Boot** в BIOS. На ThinkPad: F1 → Security → Secure Boot → Disabled. Потом загрузись с флешки (на ThinkPad — F12).

**Установка:** в окне приветствия подключись к Wi-Fi и нажми **«Установить Ember OS»**. На шаге *«Разделы»* выбери **«Стереть диск»** (или **«Установить рядом»**, чтобы оставить Windows).
После первого запуска Steam, Wine и Hydra Launcher докачиваются в фоне, а когда они будут готовы, придёт уведомление.

## Советы

- Виджет улетел за край экрана? Напиши `/widgets reset` в командной строке.
- Нет нужной программы? Попробуй `/download <название>` или посмотри список в `/apps`.
- Старый или медленный компьютер? `/little` выключает размытие, тени, тяжёлые анимации и виджеты.

## Собрать самому

```bash
docker run --rm --privileged -v "$PWD:/repo" archlinux:latest bash /repo/build.sh
# ISO появится в ./out
```
